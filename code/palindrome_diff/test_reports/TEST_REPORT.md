## 复杂度更正

U 次修改、Q 次查询、块长 B：

$$O((1+U/B)n\log(n+1)+UB+QB^2\log(n+1)).$$

当 U 与 Q 同阶时，B=Θ(n^(1/3))；U=Q=Θ(n) 时为 O(n^(5/3) log n)。此前 O(n^(3/2) log n) 的说法计算有误，已撤回。
