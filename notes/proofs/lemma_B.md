# 问题 SC 路径 1 的推导记录

## 1. 重新表述（已证）
- L* = max Λ，r = n − L*，W = B[r..n)，π 为 W 的最小周期。
- 对 p ∈ [0, L*)：p ∈ Per(W) ∪ {0} 且 r+p ∈ PPref(B) 时，L = L*−p 满足 SC 条件。
- F ↔ {p ∈ Per(W) ∪ {0} : r+p ∈ PPref(B)}。

## 2. 短周期段（p ≤ L*/2）：恰好一个 AP（已证）
- Fine–Wilf：p ≤ L*/2 时 p 是周期 ⇔ π | p。
- 引理 S：若 1 ≤ j₁ < j₂ 且 Xu^{j₁}、Xu^{j₂} 都是回文（X = B[0..r)，u = W[0..π)），则 j ∈ [j₁, j₂] 全部回文。
  证明要点：回文性给出 P₁u^k = v^k P₁（v = rev(u)，k = j₂−j₁）；由 zA = Bz 的经典引理，P₁ 是 v^∞ 的前缀；回文性只依赖长度模 π，而 r+jπ 模 π 同余。
- 推论：短周期段满足回文条件的 j 构成一个连续区间（一个 AP），至多占 1 个 PPref 组。

## 3. 长周期段（p > L*/2）：三点情形（已证）
- 设 p₁ < p₂ < p₃ 都在长周期段且回文，s₁ = p₂−p₁，s₂ = p₃−p₂，s₁+s₂ < L*/2。
- P₂ 同时有周期 s₁ 与 s₂，Fine–Wilf 给出周期 g = gcd(s₁, s₂)。
- [p₁, p₃] 内模 g 同余于 p₁ 的点全部回文，构成一个 AP，属于同一个 PPref 组。

## 4. 组数结论
- F 的组成：短段 AP（≤1 组）+ 长段 AP（三点以上时 ≤1 组）+ 至多 2 个孤立点 + p = 0。
- 三点情形下，F 命中的 PPref 组数为 O(1)。全局情形见缺口 A。

## 5. 未解决
- 缺口 A（全局长周期）：对 P_max 做 Fine–Wilf 迭代需要 (p_max−p_i)+(p_max−p_j) ≤ r+p_max，r 很小时不成立。
- 缺口 B（LCE 代价）：判定候选 AP 中哪些点确为 W 的周期，需要 W 的 border 结构，目前只能界定为 O(log) 个 dyadic 区间，总代价仍为 O(log) 次 LCE。
- 待证引理：给定模 g 类上的候选 AP，能否用 O(1) 次 LCE 判定其中哪些点是 W 的周期？若能，SC 为 O(1) 次 LCE，合并总代价约 O(log² N)。
